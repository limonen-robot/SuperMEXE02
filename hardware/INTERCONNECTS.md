# motor / sensor 実配線の記録

2026-11-13の利用者説明を反映。**コードの変更は保留し、配線されている線を図面へ記録**する。U1=sensor、U2=motor。両基板ともUSB端子を上にした部品面図で、左CN4・右CN3の30端子を表示。

| 接続 | 実配線として描いた内容 |
|---|---|
| VCT制御 | U2 motor PA0 / A0 / CN3-12 → K1リレー基板の制御入力IN |
| VCT接点 | 共通3V3 → K1 COM、K1 NO → U1 sensor PB0 / D3 / CN4-6。PA0 Highで接点を閉じ、PB0へ3.3 Vを入れる |
| 3V3共通 | U1 CN3-14 ↔ U2 CN3-14。センサー入力の上側クランプとC3/C4、リレーCOMも同じ線 |
| GND共通 | 両基板のCN3-2・CN4-4、センサー信号GND、入力回路のGNDを共通化 |
| シリアル線 | U1 sensor D1 / PA9 / CN4-1 → U2 motor D0 / PA10 / CN4-2。1方向の線として記録 |
| 外部リセット | 両基板のD0直下にあるNRST / CN4-3を共通のSW1へ接続。押すと共通GNDへ落ちる通常開の押しボタンとして表現 |

## K1の型番と全端子化

同一ASINの販売情報と商品画像でQCCAN QC19004と確認し、VCC/IN/GNDとNC/COM/NOの全6端子を表示。VCCは共通3V3、GNDはマイコンGNDへ接続しています。リレー本体は写真のBESTEP JQC3F-03VDC-Cです。裸コイルをGPIOへ接続する図ではありません。内部のジャンパー設定は未確認。端子順とZHOME用K2〜K5は[追加したドライバ配線](AZD_K_WIRING.md)を参照してください。

## 電源とリセットの表現

USB給電と3V3共通化は利用者申告の既存配線を記録したもの。USBからの電源経路・レギュレーター同士の関係・給電設定の適否は未検証で、この図から新たな接続を推奨するものではない。3V3端子は外部から見た共通レール端子としてpassive属性とし、共有レールのPWR_FLAGはERCの供給宣言にだけ使う。PWR_FLAGは追加する実部品ではなく、内部の供給元や電源間の電流を保証するものでもない。

SW1の型番・端子並びは未指定。NRSTはLowでリセットされるため、押すとGNDへ接続する等価回路として描いた。各基板の右側にもあるNRST端子は外部へ別配線していない。基板内部のリセット回路・プルアップ・コンデンサーは展開していない。

## コードとの関係（変更なし）

現行motorのPA0はVCT出力、sensorのPB0は立上がり入力なので、リレーを挟む方向は一致する。ただし接点の遅れ・チャタリングは現行コードで補正しない。接点経由での同期精度は未検証。

D1→D0線は実在する配線として描く。現行コードはこのUARTを使わず、USB経由でPCと通信する。線経由へ制御を戻すかどうかは保留であり、コードは変更していない。旧冠流量制御コードではsensor側から位置指令をこの線へ送っていた。

motorのCW/CCW・ZHOME用リレー・24 V電源も含め、同じA0横1ページへ統合済み。モータ・エンコーダ・ブレーキ・AC/PE等の実配線は未説明。現在の×印には「この図に外部配線をまだ記載していない端子」も含み、実機で未使用と断定しない。
